Kutipan Inspirasi:

"Orang jarang tertarik pada kecanggihan solusi sebelum melihat hubungannya dengan persoalan yang sungguh mereka alami."

1. Bagian 1: Pernyataan Masalah Pelanggan (CPS) Terkonfirmasi

Naufal selaku Asisten Lab Basis Data mengalami terjadinya 14 transaksi macet (deadlock) dan laporan data nilai tugas yang tertimpa ketika mahasiswa praktikan mengeksekusi kueri konkuren menggunakan akun user bersama pada sesi praktikum di lab, sehingga sesi praktikum terganggu oleh antrean keluhan mahasiswa dan asisten harus membunuh proses server secara manual. Ia membutuhkan mekanisme pemisahan ruang kerja (schema isolation) transaksi antarpraktikan yang berjalan otomatis dan bebas deadlock, dengan mempertimbangkan ketiadaan wewenang merombak akun sistem operasi server fakultas serta tidak menambah beban tiket pemeliharaan harian asisten lab.

2. Bagian 2: Matriks Analisis Detoks Fitur

Nama Fitur Manfaat Langsung Nilai Relasional (Peran) Bukti Diperlukan Keputusan
1. Skrip CLI Wrapper Pembuat Schema Otomatis (pg-session-guard) Mengarahkan koneksi sesi psql praktikan langsung ke schema privat berbasis NIM tanpa setup manual. Randy (Praktikan): Kepastian nilai aman.
Naufal (Asisten): Cegah deadlock sistemik tanpa akun OS baru.		 Teruji simulasi 2 terminal konkuren di portofolio Minggu 7. PERTAHANKAN
Solusi inti shared-credentials.
2. Dashboard Web GUI Monitoring Realtime Grafik warna-warni utilisasi CPU, RAM, lock graph di browser. Tidak relevan bagi praktikan di terminal. Bagi asisten lab, membuka browser justru memecah konsentrasi. Tidak ada permintaan dashboard visual dari asisten; CLI log mencukupi. PANGKAS
Jebakan feature dumping.
3. Notifikasi Bot Telegram saat Lock Kirim chat ke HP asisten jika kueri wait lock > 30 detik. Mengganggu dan menambah kecemasan asisten lab dengan notifikasi bising tanpa solusi penguncian. Asisten butuh pencegahan, bukan alarm kepanikan. PANGKAS
Interupsi teknologi berlebih.
4. Heartbeat Auto-Kill & Self-Reset (--reset) Putus transaksi idle 5 menit dan akses perintah satu klik reset sesi mandiri jika jaringan drop. Naufal (Asisten): Beban kerja asisten nol saat jaringan putus, karena praktikan bisa self-reset. Menjawab langsung hidden concern Naufal saat wawancara. PERTAHANKAN
Kunci persetujuan pilot.

Catatan Etis & Batas Solusi: Keterbatasan dinyatakan terbuka sejak awal; skrip ini memitigasi deadlock pada tingkat isolasi schema database lokal; verifikasi kesalahan logika sintaks SQL di dalam schema tetap menjadi tanggung jawab belajar mandiri praktikan.

3. Bagian 3: Draf Pitch Minat 60 Detik (≤ 120 Kata)

"Naufal, minggu lalu kita sudah mengonfirmasi adanya 14 benturan transaksi deadlock akibat akun lab yang dipakai bersama. Untuk mengatasi hal itu tanpa harus repot migrasi akun server kampus, aku membuatkan prototipe skrip CLI ringan bernama pg-session-guard. Cara kerjanya, saat praktikan login psql, skrip ini otomatis membuatkan schema privat berbasis NIM dan memasang timeout 5 menit, sehingga kueri Randy dan teman-teman tidak akan saling kunci. Dengan cara ini, tugas mahasiswa tidak tertimpa dan asisten lab terbebas dari repotnya mereset server secara manual. Apakah mekanisme sesederhana ini layak kita uji coba pada satu kelompok di sesi Rabu depan?"

Panjang teks: 114 kata (Memenuhi batas maksimal ≤ 120 kata).
